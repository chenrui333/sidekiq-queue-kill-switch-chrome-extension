# Privacy Policy

Sidekiq Queue Kill Switch does not collect, sell, share, or transfer user data.

The extension runs only on Sidekiq queues pages that match the extension's manifest pattern. It reads the existing Sidekiq queue page in the browser so it can add Pause All and Unpause All controls and submit the page's existing pause or unpause forms after user confirmation.

The extension does not:

- send data to the extension author or any third-party service
- collect personally identifiable information
- collect authentication information, passwords, or credentials
- collect browsing history
- collect analytics, telemetry, or usage tracking
- use remote JavaScript or WebAssembly code

Any queue action submitted by the extension is sent only to the Sidekiq site that the user is already viewing, using that page's existing forms and browser session. The extension is designed only to help operators pause or resume Sidekiq Enterprise queues.

For support, use the repository issue tracker:
